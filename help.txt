# Aruvi Server — opencode Telegram Bot Setup

## Server
- HidenCloud container, ARM64, 3GB RAM
- No SSH — access via REDACTED_DOMAIN terminal
- Persistent files: ~/code/.env (secrets), ~/code/run.py (entrypoint), ~/code/node/ (Node.js if installed)
- Repo cloned to ~/code/repo/backend/ on each restart
- Auto-restart at 3:30 AM IST (os._exit(0) in run.py for fresh IP)

## Current setup (code/run.py)
- TelePlay (FastAPI) on :24696 via tunnel at REDACTED_DOMAIN
- opencode web on :7444 (API + web UI) via tunnel at REDACTED_DOMAIN
- cloudflared tunnel with TUNNEL_TOKEN
- grinev/opencode-telegram-bot (Node.js) connects to opencode API
- Node.js 22 ARM64 downloaded to ~/code/node/ if not in PATH

## GDrive issue (fixed, committed)
- _creds_from_dict scopes fix: d.get("scopes", SCOPES) -> d.get("scopes") or SCOPES
- Prevents "Value after * must be an iterable, not NoneType" when stored token has "scopes": null
